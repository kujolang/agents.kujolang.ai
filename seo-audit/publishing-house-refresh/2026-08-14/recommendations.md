# Recommendations and measurement plan

Audit date: 2026-08-14

## Completed after deployment

- Production status, canonical, social image, hero, sitemap membership, robots
  access, and exact generated/production content match were verified on
  2026-08-14.

## Remaining operator action

- Request recrawl through authorized search consoles if available; do not claim
  indexing from submission alone.

## 7-day checks

- Inspect indexing and crawl diagnostics for `/publishing-house-system/`.
- Compare ChatGPT, organic search, and GitHub referral traffic if analytics is
  authorized.

## 28-, 60-, and 90-day comparisons

- Compare impressions, clicks, referring queries, cited URLs, and conversions
  against the deployment date without attributing causality from correlation.
- Re-crawl after any agent, tool, workflow, or skill inventory change.

## Editorial decisions

- Keep counts and canonical repository links generated or validator-enforced so
  the website cannot silently drift from the operating system.
- Add real case evidence only after rights, consent, evidence, review, and human
  approval records exist.
