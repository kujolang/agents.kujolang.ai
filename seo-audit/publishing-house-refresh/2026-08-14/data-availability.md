# Data availability

Audit date: 2026-08-14

| Source | Available | Scope / limitation |
| --- | --- | --- |
| Repository and generated output | Yes | Complete source, immutable baseline snapshot, after snapshot, and build artifacts. |
| Production HTTP delivery | Yes | Status, content, redirects, crawler user agents, robots, sitemap, and asset delivery; no CDN dashboard access. |
| Lighthouse | Yes | Mobile lab run for the new system page; not field CWV. |
| Search Console / Bing Webmaster Tools | No | No authorized indexing, query, impression, click, or submission data. |
| Analytics | No | No traffic, referral, conversion, or engagement data. |
| Search rankings | No | No controlled, signed-in, locale-specific measurement session. |
| AI-search citations | No | No authorized repeatable platform benchmark; no inclusion or citation claim. |
