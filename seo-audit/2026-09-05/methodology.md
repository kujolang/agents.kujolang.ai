# Methodology

Audit date: 2026-09-05. Scope: the entire agents.kujolang.ai canonical corpus, with editorial changes focused on Tribunal 1.0.1. Audience: developers evaluating tools, completing operator tasks, and selecting agent roles. Conversions are useful documentation and source/release navigation, not invented traffic targets. English canonical HTTPS origin: https://agents.kujolang.ai.

Baseline bytes are preserved in raw/baseline-build and sealed by baseline-artifact-sha256.json before source edits. baseline-provenance.json records the exact deployed/source revisions. The product baseline is immutable successful GitHub Pages artifact 9958285900 from run 33929513049; source equivalence was checked across all content/build inputs. Docs uses its deployed gh-pages tree; agents uses untouched tracked output after syncing published main. Local default-runtime baseline attempts timed out or failed; they are not counted as successful builds. Interpreter retries exposed existing overwrite behavior and are not a supported alternative to the documented VM build. Their logs remain raw evidence. Final builds and runtime provenance are recorded separately in after-provenance.json.

The product site builds through its pinned GitHub Pages workflow; docs builds via scripts/build_site.py and publishes generated gh-pages; agents builds its vendored SSG and commits output for Pages. Local runtime overrides stay outside tracked configuration. No sibling source, DNS, WAF, search submission, or crawler training policy was changed.

Full generated crawl covers metadata, headings, canonical/sitemap consistency, graph depth and orphans, images and responsive candidates, JSON-LD parsing, local links and complete external destinations. Manual template review checks visible entity and breadcrumb alignment; schema validity does not imply rich-result eligibility. Directory and reference word counts are informational, not automatic quality penalties. The release page, operator guide and agent review text were checked against source and operating boundaries. Topic maps and answer suitability are editorial hypotheses. Author identity or independent expertise is not invented.

Baseline and after mobile Lighthouse samples cover home, directory and detail templates. These are single lab observations under shared host load, not field Core Web Vitals. Failed Chrome interstitial samples are retained and excluded from scored comparisons; direct HTTPS and a separate Chrome page load were checked. Initial network failures can resolve on retry without a content change. Training crawlers, search crawlers and user-triggered fetchers are distinguished. Real authenticated crawler traffic and edge rules require logs. The edge-generated /cdn-cgi/l/email-protection URL is not a canonical content route; its direct-GET 404 remains in raw live receipts. Broken-internal-link metrics describe generated navigation, not this email-decoding helper.

No synthetic overall SEO or AI-readiness score is calculated. Technical defects, lab metrics and actual visibility are separate evidence layers. No ranking, citation, conversion or traffic improvement is claimed.

## Reproduction

Use the documented build and output validators. Set `NEW_AUDIT_DIR` to a newly scaffolded audit directory, then run the frozen `seo_audit.py` with `--repo . --output output --audit-dir "$NEW_AUDIT_DIR" --phase after --origin https://agents.kujolang.ai`. Run the frozen `live_crawl.py` with arguments `https://agents.kujolang.ai "$NEW_AUDIT_DIR" after`. `probe_site.py` provides redirect/crawler diagnostics. These scripts are preserved in this audit directory. Do not overwrite this audit's baseline or final records. baseline-source-map.csv supplements the generic source labels for docs and agents.
